# Project 02: To-Do List CLI

Status: Planned

## Description
A command-line to-do app applying OOP, file handling, and collections.

## Concepts Applied
- Task class with encapsulated data
- Lists to manage tasks in memory
- File handling to persist tasks between runs
- Exception handling for file operations

## Planned Features
- Add / remove / update tasks
- Mark tasks as complete
- Save and load from a JSON file
- Filter by status (pending / done)
