# Project 03: Student Grade Manager

Status: Planned

## Description
An OOP-based student record system using inheritance, file I/O, and data processing.

## Concepts Applied
- Student and GradeBook classes
- Inheritance for different student types
- File I/O to store and load records
- Dictionary and list operations for grade analysis

## Planned Features
- Add students with subject grades
- Calculate class average and individual GPA
- Find highest and lowest scorer
- Export results to CSV
