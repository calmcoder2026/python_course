# Project 01: Calculator CLI

Status: Planned

## Description
A command-line calculator applying functions, loops, and exception handling.

## Concepts Applied
- Functions with parameters and return values
- while loop for continuous operation
- Exception handling for invalid input
- if-elif for operator selection

## Planned Features
- Basic operations: +, -, *, /
- Input validation with error messages
- History of recent calculations
- Quit command to exit
